# RustAPI

A high-performance Rust scripting runtime for Geode v5.

Ported from the LuauAPI project to provide a native, safe, and fast environment for modders who prefer Rust over scripting languages.

### Features
- Native performance (no JIT or interpreter overhead)
- Full access to Geode Mod APIs
- Asynchronous networking that won't freeze your game
- ImGui integration for easy menu creation
- Sandbox-aware filesystem access
- Cocos2d-x node manipulation
